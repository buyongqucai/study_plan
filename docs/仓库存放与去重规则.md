# 仓库存放与去重规则（全项目）

适用范围：`进阶计划` 根下 **01-税务师 / 02-CPA / 03-AI管理会计师 / 04-中级 / 99-案例与求职 / tools**。

## 1. 科目内标准目录

每个考试科目目录建议：

| 目录 | 放什么 |
|------|--------|
| `01-电子教材/` | 原材料：`讲义-{东奥\|斯尔\|正保}/`、`习题-{书名}/` |
| `02-章节笔记/` | 仅自己写的 md/笔记，**禁止**再拷讲义 PDF/docx |
| `03–05/` | 科内自定义（总结、地图等）；交互做题不放这里 |
| `06-习题看板/` | 做题本 / 错题本 / 收藏题本 / 看板.html（交互唯一入口） |

税务师多科、CPA 各科、中级各科均同一套逻辑。

## 2. 品牌讲义

- **东奥 / 斯尔 / 正保** 故意多品牌并存 → **不算重复，不得互删**。
- 同一品牌下若出现两份路径（例如同步脚本拷双份）→ 保留 `01-电子教材/讲义-{品牌}/` 规范路径，删错放副本。

## 3. 交互产物

- 每科只有一个日常入口：`06-习题看板/看板.html`。
- 旧 `05-错题本` 的 HTML 交互迁走后只留说明跳转；md 备份可留。
- 脚本**不**放在某科目录内，统一 `tools/教材习题交互/`。

## 4. 去重分类

| 类 | 含义 | 动作 |
|----|------|------|
| A | 同名同大小（或哈希相同）且路径不合规的多余副本 | 保留规范路径，删除多余 |
| B | 多品牌故意并存 / 不同版本教材 | 只登记，不删 |
| C | 错放（笔记区、桌面式散落、tools 旧名并存） | 迁入规范路径或删错放拷贝 |

## 5. Git

- 继续忽略大体量 pdf/docx/视频/压缩包（见根 `.gitignore`）。
- 交互 HTML/JS、规则与清单 md 可提交。
- `06-习题看板/**/导出/*.json` 忽略。

## 6. 可复用脚本

路径：`tools/教材习题交互/`  
服务所有考试科目的习题 PDF → 做题包 / 错题合并 / 收藏合并。  
技能：`.cursor/skills/exam-pdf-quiz/`。
