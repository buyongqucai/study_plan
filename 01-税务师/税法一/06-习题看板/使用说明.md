# 06-习题看板 · 使用说明

## 唯一入口

打开 [`看板.html`](./看板.html)

| 功能 | 路径 |
|------|------|
| 第01章做题（全章 25 题） | [`必刷550/题库/第01章-税法基本原理/做题本.html`](./必刷550/题库/第01章-税法基本原理/做题本.html) |
| 错题本 | [`必刷550/错题本.html`](./必刷550/错题本.html) |
| 收藏题本 | [`必刷550/收藏题本.html`](./必刷550/收藏题本.html) |

## 流程

1. **做题**：答题卡浏览；**交卷前不露答案**。
2. **交卷**：出成绩；错题入篮 → **导出错题 JSON** → 放入 `必刷550/导出/`。
3. **收藏**：任意题点「收藏」→ **导出收藏 JSON** → 同目录。
4. 对 Agent：
   - `按习题册交互技能合并错题：…/导出/xxx.json`
   - `按习题册交互技能合并收藏：…/导出/xxx.json`
