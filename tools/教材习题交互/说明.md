# 教材习题交互（全局工具）

路径：`tools/教材习题交互/`  
适用：**税务师 / CPA / 中级** 等一切习题 PDF，不只税法一。

| 脚本 | 用途 |
|------|------|
| `渲染PDF页.py` | PDF → PNG |
| `识别页面文字.py` | OCR |
| `生成章节包.py` | JSON → 章节做题包 |
| `合并错题导出.py` | 错题 JSON → `错题数据.js` |
| `合并收藏导出.py` | 收藏 JSON → `收藏数据.js` |
| `校验题目数据.py` | 校验 |
| `页码映射-示例.json` | 书页↔PDF |

另见：`tools/扫描重复文件.py`、`tools/执行安全去重.py`；规则 `docs/仓库存放与去重规则.md`。
